# 市场验证 MVP V2：自助 SKU 30 秒广告包

## 1. 产品纠偏

4～5 秒 H3 输出不是客户交付物，只是广告生产中的镜头素材。此前按单条短候选设计 Focus / Compare / Full 和人民币价格，是错误的产品定位，已撤回。

> 用户提交一个 SKU 的完整资料，系统根据商品事实、素材、证据和投放目标排序三个适用 Creative Angle；用户选择一个主角度后，系统生成三个受控 Hook 变体，复用同一个 25 秒广告主体，最终交付三条完整、可审批、可下载的广告。

```text
SKU Product Brief
→ 完整性、证据和合规检查
→ 排序三个适用 Creative Angle
→ 用户选择一个主角度
→ 为该角度生成三个 5 秒 Hook 变体
→ 生成共享的 20 秒产品主体
→ 生成确定性的 5 秒品牌 CTA 尾卡
→ 自动组装三条完整广告
→ 商品一致性、字幕、音频和文件质检
→ 比较、审批、下载
```

产品销售单位是一个 `SKU Ad Pack`，不是 H3 秒数、VideoJob 次数或 5 秒视频。

## 2. 客户最终得到什么

一个 SKU Campaign 必须交付：

```text
Ad A：Hook Variant A 5s + 共享主体 20s + CTA 5s = 30s
Ad B：Hook Variant B 5s + 共享主体 20s + CTA 5s = 30s
Ad C：Hook Variant C 5s + 共享主体 20s + CTA 5s = 30s
```

三条广告保持不变：

```text
商品和主素材
批准卖点
目标人群
品牌调性
平台和时长
主体镜头
字幕样式
音乐
CTA
```

只改变：

```text
前 5 秒 Hook
Hook 的叙事切入
Hook 对应的第一镜头
```

因此客户比较的是同一商品的三个开场策略，而不是三条完全随机的视频。

## 3. 30 秒广告结构

| 时间 | 内容 | 生成方式 |
|---|---|---|
| 0–5s | 同一 Creative Angle 下的 Hook Variant A / B / C | 三个独立 H3 镜头 |
| 5–10s | 商品完整揭示 | 共享 H3 镜头 |
| 10–15s | 批准卖点 1 | 共享 H3 镜头 |
| 15–20s | 批准卖点 2 / 使用证明 | 共享 H3 镜头 |
| 20–25s | 品牌生活方式或英雄镜头 | 共享 H3 镜头 |
| 25–30s | Logo、批准文案和 CTA 尾卡 | 程序确定性合成，不让视频模型生成文字 |

唯一 H3 生成量：

```text
3 个 Hook × 5 秒 = 15 秒
4 个共享主体镜头 × 5 秒 = 20 秒
总计 = 35 秒 H3 素材
```

三条 30 秒广告复用共享主体，因此无需生成 90 秒独立素材。

## 4. 可用广告的最低质量合同

最终 `ApprovedDeliverable` 必须满足：

```text
30 秒，允许极小编码误差
9:16 竖版
H.264 视频
AAC 音频
商品主体清晰
不出现额外商品或错误商品
不改变核心形态、颜色和 Logo
只使用批准卖点
字幕可读且不被模型生成
包含品牌尾卡和 CTA
包含已授权音乐或客户提供音乐
可在目标平台直接上传
```

V1 不提供时间轴编辑器。字幕、Logo、CTA、音乐、转场、画布和编码由系统自动完成。

V1 不承诺 AI 配音；先使用批准卖点字幕和有授权的背景音乐。配音属于后续能力。

## 5. H3 的正确角色

H3 是镜头生成器，不是完整广告产品。

V1 优先使用：

```text
reference_image
最多 9 张商品参考图
显式 9:16 比例
4～5 秒单镜头
```

而不是让所有片段使用同一张 `first_frame`，否则每段都会重复从同一静态商品图开始，拼接后不像完整广告。

需要时可使用首尾帧控制镜头衔接；参考视频和参考音频只在真实连续性实验通过后引入，因为会增加输入成本和复杂度。

官方 H3 V2 支持首帧、尾帧、首尾帧、参考图片、参考视频、参考音频和 9:16 输出：
https://platform.minimaxi.com/docs/api-reference/video-generation-v2-create

## 6. 正确的核心对象

```text
Campaign
├── ProductBriefSnapshot
├── BrandKitSnapshot
├── CreativeAngleProposal 1 / 2 / 3
├── SelectedCreativeAngle
├── HookVariant A / B / C
├── AdPlan
│   ├── HookShotPlan A
│   ├── HookShotPlan B
│   ├── HookShotPlan C
│   ├── SharedBodyShotPlan 1～4
│   └── EndCardPlan
├── ShotVersion
│   └── VideoJob
├── AdVersion A / B / C
├── Review
├── CampaignDecision
└── ApprovedDeliverable
```

职责：

```text
CreativeAngleProposal = 根据 SKU 证据排序的低成本策略建议
SelectedCreativeAngle = 本次广告保持不变的主创意角度
HookVariant           = 只改变前 5 秒的三个受控测试变量
ShotPlan       = 单个 4～5 秒镜头的冻结配方
ShotVersion    = 镜头的 V1 / V2
VideoJob       = H3 队列执行记录
AdVersion      = 组装后的完整 30 秒广告
Review         = 审批完整广告
```

审批对象必须是 `AdVersion`。镜头级质量失败由系统内部处理，不应把七个原始片段都交给客户审批。

## 7. 质量筛选和重生成

系统先检查每个镜头：

```text
任务成功
文件可播放
时长正确
商品一致
没有额外商品
没有禁止元素
能进入对应 ShotPlan
```

失败镜头只重生成自己的 `ShotVersion`，不重跑整条 30 秒广告。

共享主体镜头失败会影响三条广告；Hook 镜头失败只影响对应的一个广告版本。

当所有必要镜头通过后，系统再组装并检查：

```text
总时长
比例和编码
字幕安全区
音频存在和音量
尾卡、Logo 和 CTA
三个广告除 Hook 外是否保持一致
```

## 8. 成本重新计算

MiniMax-H3 768P 官方价格为 ¥0.50 / 生成秒。

基础素材成本：

```text
35 秒 H3 × ¥0.50 = ¥17.50
```

包含最多两个失败镜头重试：

```text
2 × 5 秒 × ¥0.50 = ¥5.00
模型成本准备金 = ¥22.50
```

文字规划和一次模型质检在 Phase 0 样本中远低于 ¥0.10 / Campaign。仍需另计：

```text
COS 和带宽
音乐授权
微信支付手续费
合成计算
客服和退款准备金
```

一个 SKU Ad Pack 如果最终以 ¥99 测试，在最大两个镜头重试情况下，模型成本毛利约 77%。¥99 只是下一轮内部价格假设；在完整 30 秒成片通过验收前不公开、不开放 Checkout。

## 9. Phase 0 证据应该如何解释

已完成的三 SKU 九视频实验只证明：

```text
MiniMax-M3 能把固定的 pain / benefit / scene 结构转为三个结构化方案
H3 能将不同 Prompt 转为不同的 5 秒镜头
该实验没有证明 pain / benefit / scene 应成为所有 SKU 的固定分类
```

它没有证明：

```text
5 秒镜头本身值得购买
独立镜头能自动组成连贯广告
字幕、音乐、CTA 和品牌尾卡可用
客户愿意为最终广告付款
```

九条镜头中有一条引入额外商品，进一步证明质量筛选是产品核心，不是附加功能。

## 10. 下一轮产品门

在重新设计数据库、支付和自助 UI 前，必须先完成一个真实 `30s Ad Pack` 垂直切片：

```text
1 个真实 SKU
→ 3 个适用 Angle 建议，选择 1 个
→ 该 Angle 下的 3 个动态 Hook Variant
→ 4 个共享主体镜头
→ 1 个确定性 CTA 尾卡
→ 自动字幕和音乐
→ 组装 3 条 30 秒 9:16 广告
→ 商品一致性质检
→ 人工和目标客户审批
```

通过条件：

```text
三条都能直接播放和上传
三条只有 Hook 明显不同
共享主体完全一致
至少两条被评为可用于真实投放或品牌发布
没有虚假卖点、额外商品或品牌形态错误
```

此前围绕“1～3 个方向各生成一条 5 秒候选”的原子任务与价格方案已经撤回。新的实现任务必须围绕 `AdPlan / ShotPlan / AdVersion` 重新生成。

## 11. 完整垂直切片清单

### 输入

- 一个真实且有使用授权的 SKU；
- 主图和至少两张细节图；
- 商品名称、型号、规格、目标人群和平台；
- 批准卖点、禁止宣传语、必须展示和不可改变内容；
- Logo、品牌色、字幕字体、CTA；
- 一首有授权的背景音乐或客户提供音乐。

### 规划

- MiniMax-M3 根据证据与素材资格排序三个适用 Creative Angle；
- 用户选择一个主角度后，MiniMax-M3 生成三个受控 Hook Variant；
- 生成一个共享 `AdPlan`；
- 将 AdPlan 编译为 3 个 HookShotPlan、4 个 SharedBodyShotPlan 和 1 个 EndCardPlan；
- 每个计划冻结使用的事实、Prompt、模型、素材和版本。

### 镜头生产

- H3 使用商品 `reference_image`，不是每段复用同一个 first_frame；
- 显式生成 9:16、768P、4～5 秒镜头；
- 七个镜头可并行调度；
- 每个镜头保留 ShotVersion、task_id、耗时、成本和失败原因；
- 只重生成失败镜头。

### 后期组装

- 将共享主体复用到三个 AdVersion；
- 用程序叠加批准字幕、Logo 和 CTA；
- 添加授权音乐，统一音量并生成 AAC；
- 统一比例、帧率、编码、色彩空间和转场；
- 输出三条约 30 秒 H.264 / AAC MP4。

### 质量检查

- 文件、时长、比例、编码和音频检查；
- 商品、颜色、Logo、额外商品和禁止元素检查；
- 字幕安全区、可读性、批准卖点和 CTA 检查；
- 验证三条除 Hook 外的主体、字幕、音乐和 CTA 完全一致；
- 不合格镜头不得进入最终广告。

### 客户体验

- 客户只填写 Brief，不写 Prompt；
- 客户不操作画布或时间轴；
- 客户看到三条完整广告和对应 Hook 说明；
- 客户采用、驳回并选择结构化原因；
- 客户下载采用的广告和创意说明。

### 证据

- 记录总成本、生成耗时、重试数量和人工处理分钟数；
- 至少一位真实目标客户完成无指导 Brief；
- 至少两条广告被判断可以真实发布或投放；
- 从提交 Brief 到看到三条成片不超过 20 分钟；
- 不需要人工修改 Prompt、剪辑时间轴或手工改数据库。

## 12. 为什么客户不用画布和模板工具

目标客户不是需要完全创作自由的专业剪辑师。目标客户是有大量 SKU、缺少视频产能、希望快速得到合规广告变体的品牌和电商团队。

画布产品销售的是：

```text
更多编辑自由
更多模板
更多节点和参数
```

本产品销售的是：

```text
不学习工具
不写 Prompt
不搭时间轴
不处理模型废片
提交 SKU 后得到三条变量受控的完整广告
```

模板只规定版式；本系统必须完成：

```text
SKU 事实校验
品牌和合规约束
动态 Hook 规划
ShotPlan 编译
多镜头生成和重试
商品一致性质检
字幕、音乐、Logo、CTA 合成
三版本可比性
审批和版本追溯
```

客户选择本产品的唯一充分理由是：相同 Brief 下，它比自己使用画布更快、更少返工，并交付至少两条真正能发布的广告。若垂直切片不能证明这一点，产品不应继续扩张为 SaaS。

竞争边界：

```text
需要逐帧控制和复杂品牌电影 → 继续使用专业画布或代理商
只想低价抽一次模型结果     → 直接使用模型平台
需要批量 SKU 成片和 Hook 测试 → 本产品的目标客户
```
